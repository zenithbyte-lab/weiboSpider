# 微博关键词分布式爬虫 (weiboSpider)

这是一个专为新浪微博平台设计的高性能、分布式关键词抓取与分析系统。系统利用 Cloudflare Worker 代理池技术以及多线程并发机制，实现了海量数据的高效、抗风控采集。

## 🌟 核心特性
1. **多模检索**：同时运行微博移动端的**综合搜索 (`type=1`)**和**实时搜索 (`type=61`)**，在客户端去重合并，以获得最大数据覆盖度。
2. **50并发 Worker 代理池**：使用 50 个独立的 Cloudflare Workers 作为代理服务器，自动分担流量，绕过新浪的单 IP 请求频次风控。
3. **访客 Cookie 自动引导 (Visitor Bootstrapping)**：各 Worker 会独立自动注册并更新新浪微博临时访客 Cookie (`SUB` 与 `SUBP`)，无需用户手动提供登录账号。
4. **并发详情补全 (Detail Enrichment)**：对于搜出来的长微博及帖子，采用多线程并发从详情页 `/detail/{bid}` 补全完整的正文文本及 IP 属地。
5. **并发评论抓取**：自动抓取每个帖子的一级热门评论（包含评论内容、评论时间、点赞数、评论者 IP 发布地区等），可自定义单篇帖子的评论条数上限。
6. **精美 Excel 报表导出**：将抓取到的微博主帖、一级评论、统计说明分别导出为设计美观、带有冻结窗格、自动宽度、条纹底色和高级筛选功能的 Multi-Sheet 电子表格文件。

## ⚙️ 配置文件 (config.json)
您可以通过根目录下的 `config.json` 来配置所有的爬虫参数：
```json
{
  "keyword": "尼帕病毒",                           // 检索的微博关键词
  "start_date": "2026-01-15",                     // 过滤的目标起始日期 (YYYY-MM-DD)
  "end_date": "2026-03-15",                       // 过滤的目标结束日期 (YYYY-MM-DD)
  "max_pages": 90,                                // 每个搜索模式的最大翻页页数
  "max_comments": 10,                             // 每篇帖子要提取的评论条数上限
  "workers_count": 50,                            // 代理 Worker 并发线程数
  "proxy_token": "6GwzTEAATtoFmFA...",            // Cloudflare 代理授权 Token
  "output_dir": "outputs"                         // 数据保存目录
}
```

## 🚀 运行方法

### 1. 安装依赖环境
确保已安装 Python 3.9+，并在项目根目录下安装依赖库：
```bash
pip install -r requirements.txt
```

### 2. 运行完整采集流程
运行以下命令，系统将依次自动执行 **搜索 -> 正文详情补全 -> 热门评论采集 -> 导出 Excel** 的一键式流水线：
```bash
python main.py
```

### 3. 增量运行/跳过搜索
如果您已经检索了主帖日志，只想更新详情或重新抓取评论与导出报表，可以添加 `--skip-search` 标志：
```bash
python main.py --skip-search
```

### 4. 运行单机简化版 (simple_main.py)
如果您希望本地独立运行爬虫，不配置分布式 Worker 代理，可以直接运行单机版脚本：
```bash
python simple_main.py
```
*注：单机简化版是一个自包含的单个 Python 脚本文件，**只抓取主帖列表与详情页（包含全文和 IP 属地），不抓取评论**。支持自动在本地维护访客 Cookie 会话，并自动识别和解决限制。同时，单机版增大了请求随机延迟，更符合本地低频运行要求。*

## 📊 导出的 Excel 样式规范
生成的 Excel 文件样式规范如下：
1. **完整代理版 (`main.py`)**：包含三个 Sheet：
   - **`微博帖子`**：包含微博正文、话题标签、IP地区、转发数、评论数、点赞数、图片数量、视频链接、微博原文链接等字段。
   - **`微博评论`**：包含原微博摘要、评论内容、评论时间、评论点赞数、评论者发布地区/IP等字段。
   - **`统计说明`**：简述抓取的关键词、统计的帖子总量、评论总量以及时间范围等元信息。
2. **单机简化版 (`simple_main.py`)**：只包含两个 Sheet（**不带评论数据**）：
   - **`微博帖子`**：包含微博正文、话题标签、IP地区、转发数、评论数、点赞数、图片/视频链接、详情抓取状态等。
   - **`统计说明`**：简述抓取的关键词、统计的帖子总量以及时间范围等。

*注：表格使用了经典学术蓝主题色作为表头底色，正文自动换行并设定最佳列宽，冻结了首行以方便滚动阅读。*
